# Contributing

Thank you for contributing to **Orcan**.

1. Read [Development overview](https://akyther.github.io/orcan/latest/development/overview/).
2. Docs live in `docs/en/` and are versioned with **mike** (`latest` / SemVer / `dev`). Update them when behaviour changes.
3. Follow [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md).
4. Use `make validate` and `make docs-check` locally (maintainers). End-user interface is the `orcan` CLI (`./bin/orcan help`).
5. Keep user docs in simple English (B1–B2).
6. Product name is **Orcan** only in docs and user-facing text (technical ids: `orcan`, `ORCAN_*`).
7. Open a PR against `main`.

Agent-oriented rules: root `AGENTS.md` and `.cursor/rules/`.
