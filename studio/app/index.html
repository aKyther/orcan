      What does “Test connection” do?

      It checks that Studio can reach this computer and sign in as the selected user. For a new SSH server, it asks before saving that server’s public identity. It does not call Orcan, Docker, or change anything on the other computer.

      Common problems: a wrong address or port, a disconnected VPN or Tailscale network, a rejected user/password/key, or a changed server identity. The result explains which one Studio found.

      Install Orcan online

      Use the official installer on a saved local, WSL2, or SSH profile. It needs internet access, Bash, Git, and Python 3; it does not transfer Studio profiles, projects, configuration, or credentials.

      Check the destination before installing or updating Orcan.

      Copy an existing Orcan CLI (offline)

      Copy Orcan from a prepared source, such as WSL where you previously installed it with internet access. Studio does not include an Orcan installer or Docker image. The transfer needs no internet; the source must already have the CLI. Existing destination configuration and project data stay untouched. Transfer its prepared Docker image separately below.

      Transfer an Orcan image

      Copy an image already built or downloaded on a prepared source, such as your WSL installation. Studio does not download or build an image during this transfer. Choose local Linux/macOS, WSL2, or SSH profiles. Studio checks both Docker daemons and skips identical images. Transfer uses a private temporary file on this computer; allow space for the image. SSH uses each profile’s saved credentials. Removal is optional, confirmed, and never deletes project data.
