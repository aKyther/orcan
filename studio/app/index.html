      What does “Test connection” do?

      It checks that Studio can reach this computer and sign in as the selected user. For a new SSH server, it asks before saving that server’s public identity. It does not call Orcan, Docker, or change anything on the other computer.

      PROVISIONING

      Install or move Orcan to a saved profile.

      Install Orcan online

      Use the official installer on a saved local, WSL2, or SSH profile. It needs internet access, Bash, Git, and Python 3; it does not transfer Studio profiles, projects, configuration, or credentials.

      Check the destination before installing or updating Orcan.

      Install Orcan CLI offline

      Build a clean kit in WSL2 and stream it through SSH. The kit never includes profiles, configuration, projects, sandbox data, or credentials.

      Transfer an Orcan image

      Streams a Docker image from WSL2 into a remote Docker daemon. The remote profile may use System SSH or a saved password/key credential.
